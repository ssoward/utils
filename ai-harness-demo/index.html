What is an AI Harness?

An AI harness is the orchestration layer between users and an AI model. It's the middleware that makes raw AI useful in real applications.

User sends a message
|
HARNESS runs pre-processing middleware
|
HARNESS loads session context & history
|
AI Model generates a response
|
HARNESS executes any tool calls
|
HARNESS runs post-processing middleware
|
User receives the result

Try the quick prompts below or type your own message. Watch the trace panel on the right to see the harness pipeline in action.

How This Demo Works

This app is an AI harness. The server (server.js) implements the full harness pattern: middleware pipeline, session management, tool registry, and AI execution. It tries claude -p first, falls back to simulation.
