## Resume checklist for a fresh CC session

When you open a new session in this directory:

1. **Check store status first**: visit `https://chrome.google.com/webstore/devconsole` → HumanMark item → look at the **Status** column.
2. **Read this file** to see where we left off.
3. **Skim `CHANGELOG.md`** to see what's shipped.
4. **`git status`** + `git log --oneline -10` to see if anything changed locally between sessions.
5. **`npm run release:verify`** to confirm credentials still work (refresh tokens occasionally need rotating; if it fails with "invalid_grant", re-run `npx chrome-webstore-upload-keys`).
6. Decide next action based on store status:
   - **Pending review** → wait, work on deferred items (promo tile, etc.)
   - **Published** → upload latest local version via `npm run release && npm run release:publish`
   - **Rejected** → fix per the email, repackage, resubmit
7. **Update this file** at the end of the session if anything material changed.
